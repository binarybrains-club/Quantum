# Fundamentos

La superposición es que un qubit existe simultáneamente en estado 0 y 1. El entrelazamiento quántico permite que dos o más qubits estén correlacionados sin importar la distancia: lo que le sucede a uno afecta instantáneamente al otro. Al medir, los qubits colapsan aleatoriamente a 0 o 1 , donde los pesos (amplitudes) determinan las probabilidades de cada resultado, pero no garantizan cuál ocurrirá en una medición específica (puede ser 0 o 1).
