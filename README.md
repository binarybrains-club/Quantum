# Fundamentos

La superposición es que un qubit existe simultáneamente en estado 0 y 1. El entrelazamiento quántico permite que dos o más qubits estén correlacionados sin importar la distancia: lo que le sucede a uno afecta instantáneamente al otro. Al medir, los qubits colapsan aleatoriamente a 0 o 1 , donde los pesos (amplitudes) determinan las probabilidades de cada resultado, pero no garantizan cuál ocurrirá en una medición específica (puede ser 0 o 1).

### Qubit en superosición

|ψ⟩ = α|0⟩ + β|1⟩ 

**ANTES de medir:**

* El qubit está en superposición: |ψ⟩ = α|0⟩ + β|1⟩
* Existe simultáneamente como 0 y 1
* Es un estado cuántico "vivo"

**AL MEDIR:**

* El sistema colapsa a uno de los estados base
* Obtienes 0 con probabilidad |α|²
* O obtienes 1 con probabilidad |β|²

**DESPUÉS de medir:**

* El qubit ya NO está en superposición
* Ahora es definitivamente 0 o definitivamente 1
* La superposición se ha perdido (es irreversible)
* Afecta a qubits entrelazados instantáneamente, incluso a distancia
